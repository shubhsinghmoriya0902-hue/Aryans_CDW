BASED ON THE EMPIRICAL RESUME ANALYSIS, THE FOLLOWING SCORING ADJUSTMENTS ARE IMPLEMENTED:

1. DECREASED VALUES (DOWNWEIGHTED / COMMODITY SKILLS):
   --------------------------------------------------
   • Basic HTML/CSS/Bootstrap: Decreased from 0.60 to 0.40 in SDE.
     Rationale: Web markup is commoditized and often copied from tutorials; gives no signal of algorithmic capability.
   • Generic Python Scripting (without frameworks/systems context): Decreased from 1.0 to 0.75 in general SDE.
     Rationale: Python alone without backend (Django/FastAPI) or systems/data structures indicates introductory syntax only.
   • Generic Coursework Listing without Project Proof: Weight decreased in SDE from 12 to 10 points.
     Rationale: Merely listing CS courses on an IITK resume is trivial; actual projects and GitHub repos provide 3x higher signal.
   • Matplotlib / Seaborn / Basic Plotting: Decreased from 0.70 to 0.50 in ML/Data Science.
     Rationale: Basic 2D plotting is trivial boilerplate; weight shifted to model evaluation, F1/ROC-AUC, and deployment.
   • High school / Minor non-technical PoRs (School Head Boy, Club Volunteer): Downweighted in all technical tracks.
     Rationale: Has zero correlation with Day-1 placement success in SDE/Quant.

2. INCREASED VALUES (UPWEIGHTED / HIGH-DIFFERENTIATION SKILLS):
   ---------------------------------------------------------
   • C++ / Modern C++ (C++17/C++20) & DSA: Increased from 0.90 to 1.00 in SDE and Quant Finance.
     Rationale: C++ remains the absolute gold standard for Day-1 high-frequency quant and core backend systems.
   • Distributed Systems / Docker / Kubernetes / Microservices: Increased from 0.60 to 0.85-0.95 in SDE.
     Rationale: Industry recruiters heavily reward candidates with real deployment and containerization experience.
   • Numerical Analysis / Krylov Solvers / Sparse Matrices: Added with 0.90 weight in Quant & Core.
     Rationale: As observed in top IITK candidate resumes (e.g. SURGE research on Krylov solvers), advanced numerical
     computing is a premier indicator of mathematical and computational depth.
   • Quantifiable Business & Engineering Impact (%, $, latency ms, user counts): Sub-score weight increased across tracks.
     Rationale: Differentiates actionable engineers from candidates who merely describe passive tasks.
   • SURGE Fellowships / Verifiable Research Publications: Increased from 0.80 to 1.00 in Core Engineering.
     Rationale: Highest differentiation signal for research and core hardware engineering.
   • PyTorch / Transformers / Model Deployment: Increased from 0.70 to 0.95-1.00 in AI/ML.
     Rationale: Modern ML recruiters require deep learning frameworks and production deployment (FastAPI/ONNX), not toy models.
